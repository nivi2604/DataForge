# Backend

This backend scaffold provides the initial structure for DataForge.

## Folder Overview
- app/api/: API routing and dependencies.
- app/core/: Shared configuration, security, exceptions, and logging.
- app/models/: Domain models and entities.
- app/schemas/: Request and response schemas.
- app/services/: Business logic services.
- app/repositories/: Data access abstractions.
- app/pipeline/: Pipeline-related domain logic.
- app/scheduler/: Scheduling and execution coordination.
- app/middleware/: Cross-cutting request handling.
- app/utils/: Shared helper utilities.
- tests/: Test suite placeholders.
